# Registro de Utilização de Inteligência Artificial — AgroFácil

## 1. Identificação do projeto

**Projeto:** AgroFácil — API de Gestão Agrícola  
**Disciplina:** Service-Oriented Architecture (SOA)

## 2. Utilização de Inteligência Artificial

Durante o desenvolvimento do projeto AgroFácil, foi utilizada a ferramenta ChatGPT como recurso complementar de apoio técnico e educacional.

A ferramenta auxiliou na compreensão de conceitos relacionados ao desenvolvimento de APIs REST, arquitetura em camadas, persistência de dados, validações e testes automatizados.

O uso da inteligência artificial teve como objetivo facilitar o entendimento das tecnologias utilizadas, esclarecer dúvidas e apoiar a resolução de dificuldades encontradas durante o desenvolvimento.

## 3. Principais finalidades de utilização

O ChatGPT foi utilizado como ferramenta de suporte nas seguintes atividades:

- Esclarecimento de dúvidas sobre Java e Spring Boot.
- Compreensão da arquitetura Controller, Service, Repository, Model e DTO.
- Consulta de exemplos de implementação e validação de regras de negócio.
- Orientações sobre relacionamentos entre entidades no PostgreSQL.
- Explicações sobre migrações utilizando Flyway.
- Apoio na interpretação de mensagens de erro e logs do sistema.
- Orientações sobre documentação de APIs com Swagger/OpenAPI.
- Consulta de exemplos de testes automatizados utilizando JUnit e Mockito.
- Apoio na organização da documentação técnica do projeto.

## 4. Exemplos de consultas realizadas

Ao longo do desenvolvimento, foram realizadas consultas relacionadas a:

1. Como organizar uma API REST utilizando Spring Boot?
2. Qual é a função das camadas Controller, Service e Repository?
3. Como implementar relacionamentos entre entidades utilizando JPA?
4. Como validar informações recebidas pela API?
5. Como interpretar erros de execução do Spring Boot e PostgreSQL?
6. Como utilizar Flyway para versionamento do banco de dados?
7. Como configurar e acessar a documentação Swagger?
8. Como estruturar testes automatizados utilizando JUnit e Mockito?
9. Como organizar a documentação técnica de uma API para publicação no GitHub?

As perguntas acima representam os principais assuntos abordados nas interações e não constituem transcrições literais dos prompts utilizados.

## 5. Processo de desenvolvimento

O projeto foi desenvolvido de maneira incremental, utilizando o Visual Studio Code como ambiente de desenvolvimento.

Durante esse processo, foram realizadas configurações, implementações, execuções de comandos, verificações de funcionalidades e testes no ambiente local.

As orientações obtidas por meio do ChatGPT foram utilizadas como material de referência e suporte técnico durante essas atividades.

## 6. Considerações finais

A inteligência artificial foi utilizada como ferramenta complementar de consulta, orientação e aprendizagem.

Sua utilização contribuiu para o esclarecimento de dúvidas técnicas, a compreensão das tecnologias envolvidas e a resolução de dificuldades encontradas ao longo do desenvolvimento do AgroFácil.
